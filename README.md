# `prism`: Belief-Conditioned Relational Actor-Critic for Pokémon TCG (Bo3)

[![CI Tests](https://img.shields.io/badge/tests-16%20passed-brightgreen.svg)]()
[![Rust Engine](https://img.shields.io/badge/rust-compiled%20%26%20tested-blue.svg)]()

`prism` is a high-performance reinforcement learning architecture and inference engine designed for competitive Best-of-3 (Bo3) Pokémon Trading Card Game match play under strict tournament constraints (2 vCPU, $\le 12.2\text{ GB}$ RAM).

---

## Architecture Overview

```
Raw POMDP State (Rust / Python Engine)
  │
  ├──► [Module 1: 3-Segment Deck & Bayesian Belief Tracker]
  │      └── Output: b_game (Deck/Hand/Prize belief tensors), z_match (Bo3 context ∈ ℝ^64)
  │
  ├──► [Module 2: Composite Entity Tokenizer]
  │      └── Output: X ∈ ℝ^{B × N × d_model} (Board, Hand, Discards, Lost Zone, Global)
  │
  ▼
[Module 3: Relational Set Transformer Backbone] (Triggered ONLY on physical board mutation)
  │
  ├──► Writes / Updates: Field Inference Cache H_field ∈ ℝ^{B × N × d_model}
  │
  ├──► [Module 5: Dual-Horizon Value Critic]
  │      └── Outputs: V_game ∈ [-1, 1], V_match ∈ [-1, 1]
  │
  ▼
[Module 4: Autoregressive Atomic Action Decoder] (Repeated per micro-action)
  │
  ├── Ingests: Cached H_field, micro-step state c_micro, Legality Mask M_i ∈ {0, -∞}
  │
  └── Outputs: Micro-action logit distribution P(a^(k))
```

## Core Systems

### 1. 3-Segment Deck & Bayesian Belief Tracker
- **Deck Tensor Structure**: $T_{\text{deck\_belief}} \in \mathbb{R}^{B \times 3 \times \text{CardPoolSize}}$:
  - *Segment 1 (Top Stack)*: $L_{\text{top}} \le 3$ slots, deterministic discrete card IDs.
  - *Segment 2 (Middle Pool)*: Hypergeometric count probability distribution.
  - *Segment 3 (Bottom Queue)*: Ordered list $L_{\text{bot}} \le 10$ slots (via Iono / bottom-deck).
- **Deterministic Deck-Search Resolution**:
  $$\text{Prize}_{\text{exact}} = \text{InitialDeck}_{60} - (\text{VisibleBoard} + \text{Hand} + \text{Discard} + \text{RemainingDeck})$$
  Prize tokens transition instantly from uniform uncertainty to exact card IDs.
- **Re-segmentation Triggers**: `EVENT_SHUFFLE`, `EVENT_IONO`, `EVENT_CIPHERMANIAC`.
- **Bayesian Archetype Posterior**: Real-time Dirichlet/Multinomial updates over 32 meta archetypes conditioned on observed cards.

### 2. Composite Entity Tokenizer ($x_i \in \mathbb{R}^{256}$)
- Each token $x_i = \text{LayerNorm}(\text{MLP}([e_{\text{static}}(i) \parallel e_{\text{dynamic}}(i) \parallel e_{\text{zone}}(i)]))$
- **Static ($e_{\text{static}} \in \mathbb{R}^{128}$)**: 64-dim card embedding + 64-dim rule features (Stage, HP base, Type one-hot, Weakness/Resistance, Retreat cost, Attack 1 & 2 energy requirement vectors, base damage, effect flags, Ability category).
- **Dynamic ($e_{\text{dynamic}} \in \mathbb{R}^{96}$)**: Damage counters ($HP_{\text{dmg}} / 10$), 11-dim energy histogram, 64-dim LIFO evolution stack (`under_slot_1_id`, `under_slot_1_hp`, `under_slot_2_id`, `evolution_depth`, `evolved_this_turn`), tool ID, status conditions, turn effects.
- **Zone ($e_{\text{zone}} \in \mathbb{R}^{32}$)**: 12-dim zone one-hot, controller ($+1 / -1$), slot index.

### 3. Permutation-Equivariant Set Transformer Backbone
- 4 stacked Set Attention Blocks (SAB), $d_{\text{model}} = 256$, heads = 8, $d_k = d_v = 32$, $d_{\text{ffn}} = 1024$.
- Absolute positional encodings are omitted for Bench and Hand collections to enforce strict permutation equivariance.
- Pooling by Multihead Attention (PMA_1) with a learned seed vector $S \in \mathbb{R}^{1 \times 1 \times 256}$ produces permutation-invariant global state $h_{\text{global}} \in \mathbb{R}^{256}$.

### 4. Field-Inference Caching Engine
- Decouples the $O(L \cdot N^2 \cdot d)$ backbone from $O(N \cdot d)$ pointer decoder evaluations.
- **Cache Invalidation Contract**:
  - `INVALIDATE`: Card enters play, card discarded, damage counters modified, energy attached, attack resolved, shuffle executed.
  - `PRESERVE`: Intra-card sub-selections (selecting Ultra Ball discards, picking search targets, selecting retreat energy cost discards).

### 5. Autoregressive Atomic Action Decoder
- **Macro-Action Head**: Predicts distribution over 7 macro actions (`Attack`, `Retreat`, `PlayItem`, `PlaySupporter`, `AttachEnergy`, `UseAbility`, `Pass`).
- **Entity Pointer Head**: Attends over $N=64$ entities:
  $$q_t = \text{MLP}_{\text{query}}([c_{\text{micro}} \parallel h_{\text{global}}])$$
  $$\text{Logits}_i = \frac{q_t \cdot (H_{\text{field}}[i] W_K)^T}{\sqrt{d_k}} + M_i$$
  where $M_i \in \{0, -\infty\}$ is generated by the synchronous micro-step state machine.

### 6. Dual-Horizon Value Critic & Strategic Concession
- Computes game win probability $V_{\text{game}} \in [-1, 1]$ and match win probability $V_{\text{match}} \in [-1, 1]$.
- **Concession Rule**: Concedes root action nodes when:
  $$V_{\text{game}} < -0.85 \land V_{\text{match}} > V_{\text{game}} \land \text{SeriesScore} \in \{0\text{-}0, 1\text{-}0\} \land t_{\text{clock}} < 0.40$$

### 7. Devolution Knockout Check
$$\text{UnderHP} = e_{\text{dynamic}}[\text{under\_slot\_1\_hp}]$$
$$\text{IsDevolvable} = \mathbb{I}(e_{\text{dynamic}}[\text{evolution\_depth}] \ge 1)$$
$$\text{DevolKO} = \text{IsDevolvable} \land (e_{\text{dynamic}}[\text{damage\_counters}] \times 10 \ge \text{UnderHP})$$
